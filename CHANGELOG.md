# Changelog

## 3.4 - 2026-11-03

- Add a blue/teal adaptive launcher icon featuring an air conditioner and Wi-Fi.
- Support themed launcher icons on Android 13 and newer.

## 3.3 - 2026-10-18

Initial release.

- Automatic discovery of DRC-1.00 controllers on the active private Wi-Fi subnet.
- Guided AP/Auth token capture, validation, and encrypted storage.
- Live state and controls for power, temperature, mode, fan speed, and swing.
- Foreground polling with confirmed post-command state reads.
- Persistent weekly schedules executed by Android WorkManager.
- Controller-scoped Bouncy Castle TLS 1.0 compatibility.
